# 首页名片入口设计

## 目标

在黄雀小程序首页现有横幅轮播中增加第 3 张“我的名片”入口，让用户能从首页直接进入名片功能，同时保持首页长度和底部导航不变。

## 交互

- 入口位于现有首页横幅轮播，排在“电影化身 · 动作模仿”之后。
- 标题为“我的名片”。
- 副标题为“创建、展示并分享你的个人名片”。
- 点击后进入 `/pages/my-card/my-card`。
- 未登录用户沿用现有登录跳转，并在登录成功后返回名片页面。

## 视觉

- 沿用现有轮播卡片的尺寸、圆角、遮罩、文字排版和页码指示。
- 新图片使用深色紫粉科技风，与首页现有视觉保持一致。
- 主体为具有层次感的发光数字名片和简洁人物轮廓，右侧构图，给左侧标题留出清晰空间。
- 图片本身不包含文字、水印或商标，页面文字继续由 WXML 渲染。

## 实现范围

- 新增一张项目内横幅图片资源。
- 在首页轮播数据中新增名片项。
- 轮播点击处理根据每项路径导航，不影响现有电影化身入口。
- 增加针对轮播数据、导航目标和图片资源的测试。

## 非目标

- 不新增名片页面。
- 不修改名片后端接口、名片数据结构或登录体系。
- 不改变底部导航。
- 不推送、合并、上传审核或部署上线。
