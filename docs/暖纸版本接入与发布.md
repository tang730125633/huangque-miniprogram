# 暖纸版本接入与发布

本版本在现有小程序首页增加「暖纸创作」入口，进入 `paper` 分包的 26 个页面；原来的 IP12、多引擎创作、会员充值、邀请与名片分享流程继续通过原路由访问。当前未把暖纸页设为默认首页。

## 对接方式

- AppID：`wx23904aa2aa91f4d6`，沿用根目录项目配置。
- 后端：`app.globalData.apiBase`，当前为 `https://huangquechuanmei.com`。
- 登录：沿用 `pages/login/login` 和唯一的 `hq_token`，登录成功回到暖纸首页。旧用户不需要创建新账号。
- 身份：进入暖纸页面后从 `/api/auth/me` 获取；核对身份前不能写入账号草稿。
- 生成：复用 `/api/gen/pricing`、四类生成接口、任务查询和历史接口。真实价格确认后提交；网络不确定时沿用原请求编号恢复。
- 媒体：同源受保护文件携带 Bearer 下载后显示；外部 CDN 不携带账号凭证；本地媒体缓存按凭证隔离。
- 名片作品按服务端槽位上传；新用户尚无名片的 404 显示为空名片。
- 充值、邀请关系和正式名片分享使用现有页面。多轮 AI 对话、微信订阅授权及反馈发送仍不属于暖纸分包的已完成功能。

## 更新路径

1. PR 客户端回归通过后合并到本仓库 main。
2. 微信开发者工具导入仓库根目录，普通编译，首页点击「暖纸创作」。检查统一登录回跳、作品读取、确认后生成、失败恢复及充值/分享入口。
3. 使用该 AppID 上传开发版本；后台设置体验版，在真机验证 request/downloadFile 合法域名、媒体、键盘、登录、实际扣费和退款状态。
4. 微信后台提交审核，审核通过后发布，用户才会收到新版。上传开发版不等于正式发布；服务器接口发布也不会更新微信客户端页面。

微信后台读取在本次环境被浏览器安全策略阻止，当前正式版号、域名白名单和审核状态尚未核实。需要项目管理员在后台完成或提供这些状态；不能绕过限制。没有 AppSecret、支付密钥或用户凭证写入本仓库。
