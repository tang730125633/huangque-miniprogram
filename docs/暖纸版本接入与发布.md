## 更新路径

1. PR 客户端回归通过后合并到本仓库 main。
2. 微信开发者工具导入仓库根目录，普通编译，首页点击「暖纸创作」。检查统一登录回跳、作品读取、确认后生成、失败恢复及充值/分享入口。
3. 使用该 AppID 上传开发版本；后台设置体验版，在真机验证 request/downloadFile 合法域名、媒体、键盘、登录、实际扣费和退款状态。
4. 微信后台提交审核，审核通过后发布，用户才会收到新版。上传开发版不等于正式发布；服务器接口发布也不会更新微信客户端页面。

微信后台读取在本次环境被浏览器安全策略阻止，域名白名单和审核状态尚未核实。需要项目管理员在后台完成或提供这些状态；不能绕过限制。没有 AppSecret、支付密钥或用户凭证写入本仓库。
